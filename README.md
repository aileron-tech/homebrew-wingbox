# Homebrew tap for Wingbox

[Wingbox](https://github.com/aileron-tech/wingbox) gives your coding agent a map of your codebase: what a change breaks, where a symbol is used, how the architecture is layered. It runs on your machine, with no model.

## Install

```sh
brew install aileron-tech/wingbox/wingbox
wingbox install
```

`wingbox install` sets up your coding assistants (Claude Code, Codex, Cursor, Copilot) in your own settings. Then, in a project:

```sh
wingbox build
wingbox impact path/to/file
```

## Upgrade and remove

```sh
brew upgrade wingbox
brew uninstall wingbox
```

## What the formula does

- It creates a Python 3.13 environment inside the Homebrew keg and installs the Wingbox wheel and the wheels of its nine pinned dependencies from PyPI.
- Every file is pinned by the sha256 that PyPI publishes for it; pip refuses anything else.
- Nothing is compiled, so the install takes seconds on macOS (Apple silicon and Intel) and on Linux.

`Formula/wingbox.rb` is generated by `tools/generate_formula.py` from the PyPI metadata. A scheduled workflow regenerates it when a new Wingbox version is on PyPI, installs and tests it with Homebrew, and only then pushes it.

## Other ways to install

`pipx install wingbox`, `uv tool install wingbox`, the Claude Desktop extension and the Codex plugin are described in the [Wingbox README](https://github.com/aileron-tech/wingbox#readme).
